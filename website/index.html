Helium

A modern Wayland shell library wrapping layer-shika.

Getting Started

Add Helium to your Cargo.toml:

[dependencies]
helium = "0.1"

Create a bar surface:

use helium::{
    helium_config, AnchorEdge, Helium,
    adapters::{self, ClockAdapter, WorkspacesAdapter},
};

helium_config! {
    HeliumConfig {
        bar: {
            height: u32 = 42,
            modules: {
                clock: {
                    format: String = "%H:%M",
                },
                workspaces: {
                    max: u8 = 9,
                },
            },
        },
    }
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let config = HeliumConfig::load("config.json").unwrap_or_default();
    let helium = Helium::from_config(config)?;

    let _surface = helium
        .surface("heliumbar")
        .size(1920, 42)
        .anchor((AnchorEdge::Top, AnchorEdge::Left, AnchorEdge::Right))
        .exclusive()
        .build()?;

    let _registry = adapters! {
        "clock" => ClockAdapter { format: "%H:%M".into(), ..Default::default() },
        "workspaces" => WorkspacesAdapter { max: 9 },
    };

    Ok(())
}

Anchors

Position surfaces on screen edges using tuples of AnchorEdge values.

use helium::AnchorEdge;

// Top bar
surface.anchor((AnchorEdge::Top, AnchorEdge::Left, AnchorEdge::Right));

// Bottom-left corner
surface.anchor((AnchorEdge::Bottom, AnchorEdge::Left));

// Full screen
surface.anchor((AnchorEdge::Top, AnchorEdge::Bottom, AnchorEdge::Left, AnchorEdge::Right));

The IntoAnchorEdges trait is implemented for tuples of 1–4 values and converts to layer_shika::AnchorEdges internally.

Config

Use helium_config! to declare typed config structs with defaults.

helium_config! {
    HeliumConfig {
        bar: {
            height: u32 = 42,
            modules: {
                clock: {
                    format: String = "%H:%M",
                    interval_ms: u64 = 1000,
                },
            },
        },
    }
}

// Load from JSON, missing fields get defaults
let config = HeliumConfig::load("bar.json")?;

Nested structs are generated with names like HeliumConfigBarModulesClock. All types derive Debug, Clone, serde::Deserialize, and Default.

Services

Free-function wrappers for common system services.

use helium::services::{audio, backlight, power, time};

let now = time::formatted("%H:%M");
let brightness = backlight::brightness()?;
let batteries = power::batteries()?;
let volume = audio::volume()?;

Adapters

Wire config to surface properties via the Adapter trait.

use helium::adapters::{Adapter, AdapterCtx, ShellEvent};

struct MyAdapter;

impl Adapter for MyAdapter {
    fn tick(&mut self, ctx: &mut AdapterCtx) {
        ctx.set("my_prop", "hello");
    }
}

Built-in adapters: ClockAdapter (sets clock_text), WorkspacesAdapter (sets workspaces and active_workspace).
