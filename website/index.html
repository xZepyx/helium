Quick start

import helium
from helium.types import Window, Label

helium.init()

win = Window(
    namespace="hello",
    anchor=["left", "top", "right"],
    exclusivity="exclusive",
)
win.set_child(Label("hello world"))
win.show()

helium.run()

Save as bar.py and run with PYTHONPATH=builddir python3 bar.py.
