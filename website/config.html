Config

The helium_config! proc macro reference

Overview

helium_config! is a proc macro that lets you declare typed configuration structs using a concise DSL. Each field can have a type and a default value. Nested { } blocks generate recursive structs. All generated types derive Debug, Clone, serde::Deserialize, and Default, with #[serde(default)] on every field so missing JSON keys fall back to the declared default.

DSL Syntax

helium_config! {
    YourConfigName {
        field_name: Type = default_value,
        nested_block: {
            inner_field: String = "hello",
            count: u64 = 42,
        },
    }
}

Rules

ElementSyntaxGenerates
Leaf fieldname: Type = value,A field name: Type with #[serde(default)] and default value value
Nested blockname: { fields },A nested struct named ParentNameName (PascalCase) containing the inner fields
Default shorthandname: Type,Same as name: Type = Default::default(),

Generated Code

For this input:

helium_config! {
    HeliumConfig {
        bar: {
            height: u32 = 42,
            modules: {
                clock: {
                    format: String = "%H:%M",
                    interval_ms: u64 = 1000,
                },
            },
        },
    }
}

The macro generates:

#[derive(Debug, Clone, serde::Deserialize)]
pub struct HeliumConfig {
    #[serde(default)]
    pub bar: HeliumConfigBar,
}

impl Default for HeliumConfig {
    fn default() -> Self { HeliumConfig { bar: Default::default() } }
}

impl HeliumConfig {
    pub fn load(path: impl AsRef<std::path::Path>) -> Result<Self, ConfigError> {
        let content = std::fs::read_to_string(path)?;
        let config = serde_json::from_str(&content)?;
        Ok(config)
    }
}

#[derive(Debug, Clone, serde::Deserialize)]
pub struct HeliumConfigBar {
    #[serde(default)]
    pub height: u32,
    #[serde(default)]
    pub modules: HeliumConfigBarModules,
}

// ... nested structs continue ...

impl Default for HeliumConfigBar {
    fn default() -> Self {
        HeliumConfigBar { height: 42, modules: Default::default() }
    }
}

Usage

let config = HeliumConfig::load("bar.json")?;
println!("bar height: {}", config.bar.height);
println!("clock format: {}", config.bar.modules.clock.format);

Example bar.json:

{
    "bar": {
        "height": 36,
        "modules": {
            "clock": {
                "format": "%H:%M:%S"
            }
        }
    }
}
Missing fields fall back to their defaults — only interval_ms uses the default of 1000 in this example.

Variants

VariantDescription
