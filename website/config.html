Config

The helium_config! proc macro reference

Overview

helium_config! is a proc macro that lets you declare typed configuration structs using a concise DSL. Each field can have a type and a default value. Nested { } blocks generate recursive structs. All generated types derive Debug, Clone, serde::Deserialize, serde::Serialize, and Default, with #[serde(default)] on every field so missing JSON keys fall back to the declared default.

DSL Syntax

helium_config! {
    YourConfigName {
        field_name: Type = default_value,
        nested_block: {
            inner_field: String = "hello",
            count: u64 = 42,
        },
    }
}

Rules

ElementSyntaxGenerates
Leaf fieldname: Type = value,A field name: Type with #[serde(default)] and default value value
Nested blockname: { fields },A nested struct named ParentNameName (PascalCase) containing the inner fields
Default shorthandname: Type,Same as name: Type = Default::default(),

Generated Code

For this input:

helium_config! {
    Config {
        bar: {
            height: u32 = 42,
            modules: {
                clock: {
                    format: String = "%H:%M",
                    interval_ms: u64 = 1000,
                },
            },
        },
    }
}

The macro generates:

#[derive(Debug, Clone, serde::Deserialize, serde::Serialize)]
pub struct Config {
    #[serde(default)]
    pub bar: ConfigBar,
}

impl Default for Config {
    fn default() -> Self { Config { bar: Default::default() } }
}

impl Config {
    pub fn load(path: impl AsRef<std::path::Path>) -> Result<Self, ConfigError> {
        match std::fs::read_to_string(path.as_ref()) {
            Ok(content) => serde_json::from_str(&content)
                .map_err(ConfigError::parsing),
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
                if let Some(parent) = path.as_ref().parent() {
                    let _ = std::fs::create_dir_all(parent);
                }
                let default = Self::default();
                if let Ok(json) = serde_json::to_string_pretty(&default) {
                    let _ = std::fs::write(path.as_ref(), json);
                }
                Ok(default)
            }
            Err(e) => Err(ConfigError::reading(e)),
        }
    }

    pub fn reload(&mut self, path: impl AsRef<std::path::Path>) -> Result<(), ConfigError> {
        let content = std::fs::read_to_string(path.as_ref())
            .map_err(ConfigError::reading)?;
        *self = serde_json::from_str(&content)
            .map_err(ConfigError::parsing)?;
        Ok(())
    }

    pub fn save(&self, path: impl AsRef<std::path::Path>) -> Result<(), ConfigError> {
        if let Some(parent) = path.as_ref().parent() {
            std::fs::create_dir_all(parent).map_err(ConfigError::reading)?;
        }
        let content = serde_json::to_string_pretty(self)
            .map_err(ConfigError::parsing)?;
        std::fs::write(path.as_ref(), content)
            .map_err(ConfigError::reading)?;
        Ok(())
    }
}

#[derive(Debug, Clone, serde::Deserialize, serde::Serialize)]
pub struct ConfigBar {
    #[serde(default)]
    pub height: u32,
    #[serde(default)]
    pub modules: ConfigBarModules,
}

// ... nested structs continue ...

impl Default for ConfigBar {
    fn default() -> Self {
        ConfigBar { height: 42, modules: Default::default() }
    }
}

Usage

let config = Config::load("bar.json")?;
println!("bar height: {}", config.bar.height);
println!("clock format: {}", config.bar.modules.clock.format);

// Save modified config back
config.save("bar.json")?;

Example bar.json:

{
    "bar": {
        "height": 36,
        "modules": {
            "clock": {
                "format": "%H:%M:%S"
            }
        }
    }
}
Missing fields fall back to their defaults. If the file doesn't exist, load() creates the parent directories, writes the default config, and returns it. Use save() to write changes back.

ConfigError

enum ConfigError

Errors from loading or parsing configuration.

Variants

VariantDescription
Io(io::Error)The config file could not be read
Parse(serde_json::Error)The config could not be parsed as JSON
