AnchorEdge

enum AnchorEdge

One edge of the screen. Passed as tuples to SurfaceInitializer::anchor().

Variants

VariantDescription
TopAnchors to the top edge
BottomAnchors to the bottom edge
LeftAnchors to the left edge
RightAnchors to the right edge

IntoAnchorEdges

trait IntoAnchorEdges

Conversion into layer_shika::AnchorEdges. Implemented for tuples of 1–4 AnchorEdge values so you can write .anchor((AnchorEdge::Top, AnchorEdge::Left)).

Implementations

TupleExample
(AnchorEdge,).anchor((AnchorEdge::Top,))
(AnchorEdge, AnchorEdge).anchor((AnchorEdge::Bottom, AnchorEdge::Left))
(AnchorEdge, AnchorEdge, AnchorEdge).anchor((AnchorEdge::Top, AnchorEdge::Left, AnchorEdge::Right))
(AnchorEdge, AnchorEdge, AnchorEdge, AnchorEdge).anchor((AnchorEdge::Top, AnchorEdge::Bottom, AnchorEdge::Left, AnchorEdge::Right))
This trait is sealed — it cannot be implemented outside of Helium.

Helium

struct Helium

Entry point for building a shell. Call one of the constructor methods to get a ShellInitializer.

Methods

pub fn from_file(path: impl AsRef<Path>) -> ShellInitializer
Start building a Helium shell from a .slint file. The file is compiled with the Slint interpreter at runtime.
pub fn from_compilation(compilation: Rc<CompilationResult>) -> ShellInitializer
Start building from a pre-compiled Slint source. Useful when you need to load or manipulate the compilation manually.
pub fn from_source(code: impl Into<String>) -> ShellInitializer
Build from a Slint source string. Compiles the string at runtime.
pub fn from_file_with_compiler(path: impl AsRef<Path>, compiler: Compiler) -> ShellInitializer
Load a .slint file with a pre-configured Compiler. Uses tokio::runtime::Runtime::block_on to resolve the async build_from_path call synchronously.

ShellInitializer

struct ShellInitializer

Wraps a ShellBuilder before any surfaces are configured. Chain calls to .surface() to define each surface, then finish with .build().

Methods

pub fn surface(self, name: &str) -> SurfaceInitializer
Start configuring a new surface with the given name. The name must match a component exported in the Slint file.
pub fn build(self) -> Result<ShellInstance, HeliumError>
Build the shell directly using a default "Main" surface. Only call this if you haven't called .surface() — otherwise, finish with SurfaceInitializer::build().

SurfaceInitializer

struct SurfaceInitializer

Fluent builder for configuring individual surfaces. Chain dimension and anchor methods, then call .surface() for the next surface or .build() / .run() to finish.

Methods

pub fn surface(self, name: &str) -> Self
Start configuring a new surface, finalizing the current one.
pub fn height(self, h: u32) -> Self
Set the surface height in pixels.
pub fn width(self, w: u32) -> Self
Set the surface width in pixels.
pub fn size(self, w: u32, h: u32) -> Self
Set both width and height in one call.
pub fn anchor(self, edges: impl IntoAnchorEdges) -> Self
Set anchor edges using the tuple-based API. Accepts 1–4 AnchorEdge values.
pub fn exclusive(self) -> Self
Infer an exclusive zone from the surface dimensions. The compositor will reserve space for the surface, preventing windows from overlapping it.
pub fn exclusive_zone(self, zone: i32) -> Self
Manually set the exclusive zone in pixels. Negative values are permitted.
pub fn namespace(self, ns: &str) -> Self
Set the namespace (app id) for the surface.
pub fn monitors(self, policy: MonitorPolicy) -> Self
Set which monitors the surface appears on.
pub fn build(self) -> Result<ShellInstance, HeliumError>
Build the shell and return a runtime handle. Call .run() on the runtime to start the event loop.
pub fn run(self) -> Result<(), HeliumError>
Build and run the shell event loop (blocks the current thread). Equivalent to .build()?.run().

Macros

helium_config!

Declare typed config structs with defaults. Generates nested serde-deserializable structs with Default, load(path), save(path), and reload(path) methods.

helium_config! {
    Config {
        bar: {
            height: u32 = 42,
            modules: {
                clock: { format: String = "%H:%M" },
            },
        },
    }
}

helium_struct!

Generate a plain struct with Debug, Clone, PartialEq, public fields, and a new() constructor.

helium_struct! {
    Foo {
        name: String,
        count: i32,
    }
}

helium_model!

Generate a Slint-compatible model wrapper around Vec<T>. Exposes push, clear, from_vec, set_vec, and row_count. Implements Into<slint_interpreter::Value>.

helium_model! { MyModel(String) }

let model = MyModel::from_vec(vec!["a".into(), "b".into()]);
let value: slint_interpreter::Value = model.into();

adapters!

Concise adapter registration macro.

adapters! {
    "clock" => ClockAdapter { format: "%H:%M".into(), ..Default::default() },
    "workspaces" => WorkspacesAdapter { max: 9 },
}
