Compositors

Auto-detect and communicate with your Wayland compositor

Detection

Call compositors::detect() to auto-detect the running compositor. It checks environment variables in order:

PriorityCompositorEnv var
1HyprlandHYPRLAND_INSTANCE_SIGNATURE
2NiriNIRI_SOCKET
3SwaySWAYSOCK
4MangoWM(env var not yet documented)
use helium_wsl::compositors;

let mut compositor = compositors::detect()?;
println!("workspaces: {:?}", compositor.workspaces());
println!("active: {:?}", compositor.active_workspace());

Compositor Trait

trait Compositor

Unified interface for compositor IPC. Each supported compositor implements this trait by connecting to its Unix socket and parsing its protocol.

MangoWM

MangoWM IPC is not yet documented by the project. The backend is a stub.

struct MangoWM
pub fn connect() -> Result<Self, HeliumError>
Returns an error — MangoWM IPC is not yet supported.
pub fn is_running() -> bool
Always returns false until IPC docs are published.
