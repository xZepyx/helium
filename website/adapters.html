Adapters

Plug-in trait that wires config data to surface properties

Overview

Adapters are the bridge between your data sources (services, config, compositor state) and your Slint UI properties. They implement the Adapter trait and are registered with the adapters! macro or AdapterRegistry.

Adapter Trait

trait Adapter

All methods have default no-op implementations — override only what you need.

fn init(&mut self, ctx: &mut AdapterCtx)
Called once when the adapter is registered. Use this to set initial property values.
fn tick(&mut self, ctx: &mut AdapterCtx)
Called on every frame tick. Update time-based properties here.
fn on_event(&mut self, event: &ShellEvent, ctx: &mut AdapterCtx)
Called when a shell event occurs (workspace change, window focus, etc.).

AdapterCtx

struct AdapterCtx

Context handle provided to adapter methods. Adapters use this to read and write surface properties.

pub fn set(&self, prop: &str, val: impl ToString)
Set a surface property to a string value. The property name must match an in property in your Slint file.
pub fn get(&self, prop: &str) -> Option<String>
Get the current value of a surface property.

ShellEvent

enum ShellEvent
VariantDescription
TickRegular frame tick
WorkspaceChangeThe active workspace changed
WindowFocusA different window received focus

adapters! Macro

Convenience macro for registering named adapters:

let registry = adapters! {
    "clock" => ClockAdapter { format: "%H:%M".into(), ..Default::default() },
    "workspaces" => WorkspacesAdapter { max: 9 },
};

Returns a Vec<(&str, Box<dyn Adapter>)> suitable for AdapterRegistry::new().

AdapterRegistry

struct AdapterRegistry

A registry of named adapters. Manages lifecycle — init, tick, and event dispatch.

pub fn new(pairs: Vec<(&str, Box<dyn Adapter>)>) -> Self
Create a registry from a list of (name, adapter) pairs.
pub fn init_all(&mut self, ctx: &mut AdapterCtx)
Initialize all adapters. Calls init() on each.
pub fn tick_all(&mut self, ctx: &mut AdapterCtx)
Tick all adapters. Calls tick() on each.
pub fn event_all(&mut self, event: &ShellEvent, ctx: &mut AdapterCtx)
Send an event to all adapters. Calls on_event() on each.
pub fn names(&self) -> impl Iterator<Item = &str>
Iterate over the names of all registered adapters.

ClockAdapter

struct ClockAdapter

Sets the clock_text surface property to the current time on every tick.

FieldTypeDefaultDescription
formatString"%H:%M"strftime format string

Implements Adapter: calls ctx.set("clock_text", time::formatted(&self.format)) on every tick.

WorkspacesAdapter

struct WorkspacesAdapter

Sets workspaces and active_workspace surface properties from compositor state.

FieldTypeDefaultDescription
maxu89Maximum number of workspaces to track
On init(), sets workspaces to a JSON array of workspace numbers and active_workspace to "1". On WorkspaceChange events, updates active_workspace.
