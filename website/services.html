Services

Free-function wrappers for system services

Overview

The services module provides stateless, free-function wrappers for common system services. Each module is feature-gated: simple backends (sysfs, chrono) are always available; D-Bus backends require the services feature (enabled by default).

ModuleBackendFeature
audioPipeWire / PulseAudioservices
backlightsysfs (/sys/class/backlight)always
bluetoothBlueZ (D-Bus)services
networkNetworkManager (D-Bus)services
powerUPower (D-Bus)services
powerprofilespower-profiles-daemon (D-Bus)services
timechronoalways
The services feature pulls in zbus and inotify. D-Bus backends are stubs when the feature is disabled.

audio

System audio volume and mute state via PipeWire or PulseAudio.

use helium_wsl::services::audio;

let vol = audio::volume()?;
audio::set_volume(0.5)?;
let muted = audio::muted()?;
audio::toggle_mute()?;

Types

struct AudioState
FieldTypeDescription
volumef32Volume as 0.0–1.0 fraction
mutedboolWhether audio is muted

Functions

pub fn volume() -> Result<f32, String>
Get the current system volume as a 0.0–1.0 fraction.
pub fn set_volume(v: f32) -> Result<(), String>
Set the system volume. Clamped to 0.0–1.0.
pub fn muted() -> Result<bool, String>
Check whether system audio is muted.
pub fn toggle_mute() -> Result<(), String>
Toggle mute state.
pub fn on_change(cb: impl Fn(AudioState) + Send + 'static) -> Result<(), String>
Register a callback invoked on audio state changes.

backlight

Read and set display backlight brightness via sysfs.

use helium_wsl::services::backlight;

let b = backlight::brightness()?;
backlight::set_brightness(0.8)?;

Types

enum BacklightError
VariantDescription
NoDeviceNo backlight device found in /sys/class/backlight
Io(io::Error)I/O error reading or writing sysfs
Parse(String)Failed to parse brightness value

Functions

pub fn brightness() -> Result<f32, BacklightError>
Get the current brightness as a normalized 0.0–1.0 fraction. Reads /sys/class/backlight/*/actual_brightness and max_brightness.
pub fn set_brightness(v: f32) -> Result<(), BacklightError>
Set the backlight brightness. v is clamped to 0.0–1.0.
pub fn on_change(cb: impl Fn(f32) + Send + 'static) -> Result<(), BacklightError>
Register a callback for brightness changes. Uses inotify when the services feature is enabled.

power

Battery status via UPower D-Bus.

use helium_wsl::services::power;

for battery in power::batteries()? {
    println!("{}% {}", battery.percentage, if battery.charging { "charging" } else { "discharging" });
}

Types

struct Battery
FieldTypeDescription
percentagef32Battery charge percentage 0.0–100.0
chargingboolWhether the battery is currently charging
time_to_emptyOption<Duration>Estimated time until battery is empty (discharging only)
time_to_fullOption<Duration>Estimated time until battery is full (charging only)

Functions

pub fn batteries() -> Result<Vec<Battery>, String>
Get current battery states from UPower.
pub fn on_change(cb: impl Fn(Vec<Battery>) + Send + 'static) -> Result<(), String>
Register a callback for battery state changes.

time

Current local time formatting via chrono. Always available (no feature gate).

use helium_wsl::services::time;

let now = time::now();
let formatted = time::formatted("%H:%M:%S");

Functions

pub fn now() -> chrono::DateTime<Local>
Get the current local time.
pub fn formatted(fmt: &str) -> String
Format the current local time using a strftime format string (e.g. "%H:%M").
